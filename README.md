# BIP-110 Umbrel Community App Store

> **Retired.** BIP-110 was a temporary soft fork, and the period this project was built to
> visualise has passed. It is no longer maintained and has been removed from the Start9 and
> Umbrel app stores. Installed copies will receive no further updates. For a block explorer,
> use the official Mempool app, or Mempool Pruned on a pruned node.

A community app store for [Umbrel](https://umbrel.com) providing tools to visualize and monitor [BIP-110 (Reduced Data Temporary Softfork)](https://github.com/dathonohm/bips/blob/reduced-data/bip-0110.mediawiki) activation progress on the Bitcoin network.

## Apps

None. Mempool BIP-110 was the only app in this store and has been removed. If you added
this store to your Umbrel, you can remove it under App Store, Community App Stores.
